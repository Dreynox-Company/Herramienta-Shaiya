# Revisión 0.6.1: compatibilidad y vuelo

Base recuperada: 307a1a7dd8992118f68b74a0bfdbecb0d2bee152.

Esta rama prepara diagnóstico local de contenedores SPK, anclaje de alas desde la pose de enlace 3DC y el panel derecho basado en el HTML V3 aportado. El data.spk real de 3.7 GB todavía no está disponible para validación.

No se atribuye soporte de descifrado a una extensión ni a la entropía de sus bytes. Una firma reconocida no implica que se haya validado su índice. El diagnóstico debe leer rangos acotados, conservar intactos SPK y biblioteca activa, y poder exportar su informe sin subir archivos automáticamente.

Los suplementos de vuelo deben identificar arquetipo, sexo y jerarquía. El perfil HUMF no se aplica a otros esqueletos por aproximación.

Este documento no certifica una compilación ni una prueba final. La entrega deberá incluir resultados reales, fuentes consolidadas y scripts de compilación con parada ante errores.
