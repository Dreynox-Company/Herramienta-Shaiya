# Herramienta Shaiya

Aplicación nativa Flutter para inspeccionar una biblioteca local DATA de Shaiya en Windows y Android. No utiliza HTML ni WebView y no modifica los recursos originales.

El código de la migración se desarrolla en una rama independiente. Los modelos, texturas, sonidos y archivos del juego no se publican en este repositorio. Los nombres de archivos originales se conservan como identificadores técnicos; la interfaz se presenta en español.
